# Epic 4 Stories: Theming and device support

## Story 4.1: Switch between light and dark mode
**Work Item:** [XC-13](../../board.html#XC-13)

**Covers:** R13, NF3

As a user, I want to use the app in light or dark mode, so that it is comfortable to read in any setting.

**Acceptance criteria**
- I can choose between light mode and dark mode.
- Every screen looks polished in both modes, with text and images easy to read.
- The app remembers my choice the next time I open it.

## Story 4.2: Use the app on desktop and mobile browsers
**Work Item:** [XC-14](../../board.html#XC-14)

**Covers:** R14, NF2

As a user, I want the app to work on both my laptop and my phone's browser, so that I can use it wherever I am.

**Acceptance criteria**
- All the app's screens and actions work in desktop and mobile browsers.
- On a phone-sized screen, nothing is cut off and I can use it without zooming.
